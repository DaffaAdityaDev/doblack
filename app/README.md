# DOBLACK — Full Web App (Login Gate + Corporate Profile)

Versi gabungan lengkap yang siap di-deploy. Berisi halaman pembuka (*private gate*), sistem login modal, dan seluruh section corporate brand profile DOBLACK secara utuh.

---

## Fitur Lengkap

### 1. Gate / Opening Screen
- Cover visual DOBLACK dengan tombol **ENTER DOBLACK**.
- Top navigation & menu pembuka login modal.
- Kartu enter interaktif & link sosial.

### 2. Private Login Modal
- Modal popup login (username & password).
- Demo credentials:
  - **Username:** `admin`
  - **Password:** `doblack2025`
- Disimpan di `sessionStorage` (otomatis tetap terbuka saat di-refresh).
- Tombol **LOCK / LOGOUT** di navbar corporate profile untuk kembali mengunci website ke halaman cover.

### 3. Full Corporate Profile
- **Hero Section:** Tagline, deskripsi brand, tombol CTA.
- **01 / ABOUT:** Filosofi brand.
- **02 / COLLECTION:** Katalog 4 produk unggulan (*Essential Tee, Signature Hoodie, Daily Jacket, Signature Pants*).
- **03 / DETAILS:** Poin keunggulan (*Material, Fit & Cut, Construction, Packaging*).
- **04 / LOOKBOOK:** Grid visual campaign foto (*4 slot campaign*).
- **05 / DIRECTION:** Visi dan fase ekspansi brand (*The Next Chapter*).
- **06 / PARTNERSHIP:** Call to action kerja sama & bisnis (*Contact Business*).
- **07 / CONTACT:** Link WhatsApp Business, Instagram resmi, dan email resmi.
